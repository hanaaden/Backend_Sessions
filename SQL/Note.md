# DDL
is data definition language using SQL commands such as altering and deleting database 
this is used to manage the structure of database 
DDL commands are auto-committed, meaning changes are saved permanently and cannot be rolled back. 

- find practicing example in DDL.sql file

# DML 
is used to monupilate date stored in database tables like inserting deleting and updating 
It includes commands that insert, update, delete, and retrieve data
DML commands are not auto-committed, allowing changes to be rolled back if necessary. 

 - find practicing examples in DDL.sql files
